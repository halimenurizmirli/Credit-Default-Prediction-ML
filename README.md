# Credit-Default-Prediction-ML

This repository contains a machine learning classification project on credit card default prediction using the UCI Default of Credit Card Clients dataset.
To run the project, install the required libraries and execute the notebook.


How to run it?
pip install -r requirements.txt
open notebook.ipynb and run

Dataset: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
